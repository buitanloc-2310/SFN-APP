## Important remaining limits
This audit must NOT be labeled `WEB STABLE / READY` yet.

Reasons:
- Browser E2E could not be executed because Chromium's GPU process fails in the current execution environment.
- Card Studio still lacks the complete requested image-upload/crop/layer/undo/redo feature set.
- PNG/JPG code is implemented but requires a real browser runtime to validate rasterization with actual R2/QR assets.
- Production deployment, real D1/R2, real authentication, uploads and QR scanning were not claimed as PASS because no production credentials/environment were supplied for this audit.

## Release rule
Do not call the web production-ready solely because source/build tests pass. The remaining browser and Card Studio gaps must be resolved and regression-tested before declaring `WEB STABLE / READY`.
